# AgendaPro

Aplicativo de gestão para profissionais de beleza (unhas, cabelo, estética).

## Funcionalidades

- Agenda diária com busca
- Cadastro de serviços e preços
- Clientes com histórico
- Lembretes via WhatsApp
- Exportação de dados
- Funciona offline (PWA)
- Dados salvos no navegador

## Como usar

1. Acesse a página do GitHub Pages
2. Ou abra `index.html` localmente
3. Para instalar no celular: abra no Chrome → “Adicionar à tela inicial”

## Deploy

Já configurado com GitHub Pages.  
Qualquer alteração no `main` atualiza automaticamente.

## Tecnologias

- HTML + CSS + JavaScript puro
- localStorage
- Service Worker (PWA)
- Manifest
