# AgendaPro

Aplicativo de gestão para profissionais de beleza (unhas, cabelo, estética).

## Funcionalidades

- Agenda diária com busca
- Cadastro de serviços e preços
- Clientes com histórico
- Lembretes via WhatsApp
- Exportação de dados (JSON)
- Funciona offline (PWA)
- Dados salvos no navegador (localStorage)
- Interface moderna com suporte a tema claro/escuro

## Como usar

1. Abra o `index.html` no navegador
2. Ou faça o deploy no GitHub Pages
3. No celular: abra no Chrome → menu → “Adicionar à tela inicial”

## Arquivos

| Arquivo        | Descrição                          |
|----------------|------------------------------------|
| index.html     | Aplicativo principal               |
| logo.png       | Logo do aplicativo                 |
| manifest.json  | Configuração PWA                   |
| sw.js          | Service Worker (cache offline)     |
| README.md      | Este arquivo                       |

## Deploy no GitHub

1. Crie um repositório
2. Faça upload de todos os arquivos desta pasta
3. Ative GitHub Pages (Settings → Pages → Deploy from main)
4. Acesse a URL gerada

## Tecnologias

- HTML5 + CSS3 + JavaScript puro
- localStorage
- Service Worker
- Web App Manifest
